
# Как работать с локальными версиями питона КОД и КОМЕНТЫ

## Немного о главном

Для работы с питоном желательно создавать локальные версии питона. Это необходимо для того чтобы в случае обновления питона, или его библиотек не ломался большой код, потому что бывают разные ситуации и с обновлениям могут измениться функции которыми пользовались при создании проекта.
## Команды

### Шаг 1

Для создания виртуального окружения необходимо в нужной нам папке например (D:\Файлы с рабочего стола\Универ\Магистратура\1 курс\Virtual environment) открыть командную строку и написать команду:

```bash

python -m venv my_venv  

```

В Windows "python", В Linux "python3"

Здесь 'python' - это команда для запуска питона, '-m venv' - это команда для создания виртуального окружения, 'my_venv' - это название виртуального окружения.
### Шаг 2

После создания локального питона необходимо переключить использование питона с глобального на локальный это выполняется за счет команды в консоле  (Powershell) для Windows

```bash

/my_venv/Scripts/activate.ps1

```

Если команда сработала правильно в консоле перед путем в папку появится (имя папки вашего локального питона в скобках)  

```bash
(my_venv) PS D:\Файлы с рабочего стола\Универ\Магистратура\1 курс\Virtual environment>

```

Для Linux

```bash

source my_venv/bin/activate.bat

```

Для проверки питона на Linux используется команда which или where
which - показывает какой питон используется в данный момент
where - первая строка это питон который используется  в данный момент, следующие строки питоны которые есть на пк
  
```bash

where python3
which python3

```

Для Windows есть альтернативная команда which, она показывает какой питон используется

```bash

Get-Command python | Select-Object Source

```

Если необходимо перестать использовать локальный питон необходимо написать команду 

```bash

deactivate

```

Данная команда работает на Windows и Linux.
Также можно указать деактивационный скрипт напрямую, указав путь к нему

```
.venv\Scripts\deactivate.bat  ------ В Linux
```

```
.venv\Scripts\deactivate.ps1  ------ В PowerShell Windows
```

## Скачивание библиотек

Обычно скачивание библиотек в питон происходит за счет встроенной функции __pip__.
Существует его аналог позволяющий скачивать модули быстрее за счет загрузки в несколько потоков __uv__ --> аналог
Для установки __uv__ необходимо написать обычную команду
```
python pip install uv. 
```

После этого можно работать с 
```
python uv pip install ..... 
```
Выше описанный способ подходит только для скачивания одной библиотеки.
Для установки сразу нескольких библиотек используют файл в котором прописывают все необходимые библиотеки и их версии, после этого файл  называют requirements.txt. Для установки всех библиотек нужно написать команду. Для более быстрого скачивания рекомендуется  сначала скачать __uv__ и потом уже с помощью него установить остальные пакеты

```
python uv pip install -r requirements.txt 
```

В файле reqirements.txt библиотеки пишутся в таком виде:
__название библиотеки == версия библиотеки__
Например:
numpy==2.5.3
pandas==3.4.5
