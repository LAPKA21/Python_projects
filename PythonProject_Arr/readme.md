## Количество элементов в массиве N = 1000000

Время затраченное на список --> Измерение не проводилось \

## Вывод:

Big O для методов
List --> O(N^2)
Set --> O(N)
NumPy --> O(N)

Самым лучшим вариантом оказалось множество Set из-за того что множество использует хэш-таблицу
